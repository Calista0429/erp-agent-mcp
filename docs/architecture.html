erp-agent-mcp Architecture

An MCP runtime where AI agents read an ERP freely and write only through plans a human approves

Agents propose, humans approve

  • • Write tools return a dry-run diff, never write
  • • Only human admins approve, via a separate CLI
  • • Idempotency keys stop duplicate orders
  • • Optimistic locking; plans expire in 15 min

Schema → tools

  • • Models and commands are TypeScript files
  • • Tools and JSON Schemas generated per role
  • • Hidden fields don't exist in any tool input
  • • Hot reload → tools/list_changed

Isolation in the database

  • • FORCE ROW LEVEL SECURITY on tenant tables
  • • Tenant set per transaction, not per query
  • • Token lookup via SECURITY DEFINER function
  • • App role can't delete or edit audit rows
